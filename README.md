# Offline Smart Scheduler

## Track F — Open / Wildcard

Our project belongs to **Track F — Open / Wildcard** because it is an
**offline scheduler**, and schedulers are specifically included in this track.

## About the Project

Offline Smart Scheduler is a simple Python program that helps users
create and manage their tasks.

Users can:

- Add tasks
- View tasks
- Search for tasks
- Filter tasks
- Mark tasks as completed
- Delete tasks
- Save tasks locally

The project works completely offline.

## Features

- Simple and easy to use
- Works without internet
- Tasks are stored locally
- Search and filtering
- Task completion
- No external services

## Technology

- Python 3
- Python Standard Library

## Zero Dependencies

This project uses no external Python packages or libraries.

We achieved zero dependencies by using only Python's built-in features
and standard library.

We did not use:

- Third-party packages
- External APIs
- Online services
- Internet connection

This makes the scheduler lightweight and easy to run on different
computers.
